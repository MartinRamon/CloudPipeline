# CloudPipeline

Pipeline de datos de extremo a extremo sobre los registros de viajes de taxis y VTC de Nueva York (NYC TLC). Ingesta los ficheros mensuales en capas bronce, plata y oro en Databricks, los modela con dbt y los orquesta con Airflow, con pruebas de calidad e integración continua.
